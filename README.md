# SMA Research Analysis
## Overview
This project investigates the relationship between temperature, prestrain, shape recovery, and residual strain in NiTi-based Shape Memory Alloys (SMAs).
The project uses experimental data extracted from published research literature and analyzes the data using Python.
## Research Question
How do temperature and mechanical loading conditions affect shape recovery and residual strain in Shape Memory Alloys?
## Objectives
- Investigate the effect of prestrain on recovered strain.
- Investigate the effect of prestrain temperature on shape recovery.
- Examine residual strain under different experimental conditions.
- Analyze experimental data using Python.
- Identify trends that may help understand SMA shape-recovery behavior.
## Research Background
Shape Memory Alloys are smart materials that can recover a previously trained shape when subjected to appropriate thermal or mechanical conditions.
This project focuses on the relationship between martensitic deformation, temperature, recovered strain, and residual strain.
## Dataset
The current dataset contains experimental data extracted from published research.
Variables include:
- Prestrain (%)
- Prestrain temperature (K)
- Recovered strain (%)
- Residual strain (%)
The dataset is stored in:
`Dataset_final.csv`
## Methodology
1. Identify relevant experimental research literature.
2. Extract experimental data from published figures.
3. Organize the data into a structured CSV dataset.
4. Use Python and pandas for data processing.
5. Use matplotlib for visualization.
6. Compare recovered and residual strain under different conditions.
7. Interpret the observed trends.
